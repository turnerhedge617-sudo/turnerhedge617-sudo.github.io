# Junaid Ahmad — Academic Portfolio

This is a responsive, static academic portfolio website. It can be hosted free with GitHub Pages.

## Publish with GitHub Pages
1. Sign in to GitHub.
2. Create a **public** repository named exactly `YOUR-GITHUB-USERNAME.github.io` (replace with your GitHub username).
3. Upload `index.html` from this folder to the repository root and commit the change.
4. Open the repository's **Settings → Pages**. If asked for a source, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait a few minutes and visit `https://YOUR-GITHUB-USERNAME.github.io`.

## Before publishing
- Review all details carefully and correct anything that does not match your records.
- Add only a professional email address or profile link you want public.
- Do not publish transcripts, identity documents, signatures, home address, or referees' contact details without considering privacy and getting permission where needed.
- The site intentionally does not claim publications or unverified thesis methodology/results.
